# FINDLY – Community Lost & Found Portal

## 📌 About the Project
Findly is a web-based application that helps people report, search, and recover lost and found items. It is designed for colleges and public places to make the process of finding lost belongings easier.

## 🎯 Objectives
- To help users report lost items.
- To allow users to post details of found items.
- To make searching for lost belongings easy.
- To reduce dependence on notice boards and WhatsApp groups.
- To connect people who have lost items with people who have found them.

## ✨ Features
- User Registration and Login
- User Authentication
- Report Lost Items
- Report Found Items
- Search and Browse Items
- Item Details and Descriptions
- Claim Management
- Database Management
- Responsive User Interface

## 🚀 How to Use
1. Register or log in to your account.
2. Report a lost item or a found item.
3. Enter the item's name, category, description, location, and date.
4. Browse or search the available listings.
5. Contact the relevant user or follow the available claim process to recover the item.
